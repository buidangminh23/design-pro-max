Questions people ask before installing

Does Beacon read what I type?

No. It records which app is in front and for how long, nothing inside the windows.

Can I delete my history?

Yes. The log is one file; delete it from the settings or the file system.

Does it slow the computer down?

It wakes once a minute and writes a single line.
