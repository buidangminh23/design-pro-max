# Rota

Rota is a web app for a chain of six cafes: staff see their shifts, swap them, and managers publish the week's rota.

- Stack: a server-rendered web app at https://rota.example.com, already responsive and used daily in mobile Safari and Chrome.
- What staff asked for: an icon on the phone instead of a bookmark, and a notification when a manager publishes the rota or approves a swap.
- About 120 staff, all on their own phones; most use iPhones, some Android.
- No camera, files, Bluetooth, background location or other device features are needed.
- One developer, part time. Every web change today goes live the same day.
- Nobody has an Apple Developer Program membership yet.
